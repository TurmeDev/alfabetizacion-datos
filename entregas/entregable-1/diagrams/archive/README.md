# Artefactos históricos del flujograma

Este directorio conserva la versión ANSI segmentada del flujograma y las
utilidades que la generaban o previsualizaban. Se archivaron el 2026-09-04 al
adoptar el flujograma de una página como referencia activa del borrador.

No editar estos archivos para producir la entrega actual. La fuente activa es
`../flujograma-formal-una-pagina.svg`, generada por
`../build-one-page-flow-svg.mjs`.
